# EarthTime 1.2.3

Два варианта для **Windows x64** — выберите один EXE:

| Файл | Возможности |
| --- | --- |
| `EarthTime-v1.2.3-windows-amd64-relief.exe` | Объёмный рельеф NOAA ETOPO 2022, горы и океанские впадины, масштаб ×1–×50, просмотр дна и две детализации. |
| `EarthTime-v1.2.3-windows-amd64-textures.exe` | Гладкая сфера с фототекстурами. Без данных высот, батиметрии и построения геометрии рельефа; меньше нагрузка на GPU и память. |

В обоих вариантах:

- Текстуры поверхности NASA Blue Marble, ночных огней и облаков размером 8192×4096.
- 55 населённых пунктов и отдельная необитаемая опорная точка UTC−12; покрытие 40 смещений UTC с сезонными вариантами.
- Алматы и Улан-Батор, крупные города Южной Америки и Африки.
- Текущее время по зонам IANA, поиск и переход камеры к выбранному городу.
- Затемнение по реальному положению Солнца: сейчас или на выбранную дату и время UTC.
- Все текстуры и данные встроены, работа без интернета.

Рельеф — глобальная обзорная модель с шагом 6′ (около 11 км у экватора). По умолчанию высоты усилены в 20 раз; масштаб ×1 соответствует пропорциям Земли. Узкие пики и желоба могут попадать между узлами.

Перед выпуском проверены ориентация рельефа, шов ±180°, расположение городов и совпадение всех 6 480 000 отметок с исходными данными NOAA. Уточнены городские ориентиры по GeoNames. Пройдены тесты Go, TypeScript и производственная сборка обоих вариантов.

**Запуск:** скачайте EXE выбранного варианта и откройте его. Нужен Microsoft Edge WebView2 Runtime и поддержка WebGL. Установка Go или Node.js не требуется.

`SHA256SUMS.txt` содержит контрольные суммы обоих EXE. Исходный код и сведения о лицензиях текстур доступны в репозитории.
